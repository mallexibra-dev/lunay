Bagian ini membahas konvensi dasar yang dipakai di seluruh proyek.

1. [Variabel Lingkungan](/docs/fundamental/environment): pola akses env terpusat lewat `src/env.ts`, aturan `NEXT_PUBLIC_`, dan cara menambah variabel baru.
2. [Routing](/docs/fundamental/routing): App Router, layout, halaman dinamis, dan penulisan route handler API dengan wrapper seragam.
3. [Styling & Tema](/docs/fundamental/styling): Tailwind v4 berbasis CSS, token warna di `variables.css`, dark mode yang sudah terpasang, dan penggabungan class dengan `cn()`.
