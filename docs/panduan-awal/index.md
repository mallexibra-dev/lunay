Next.js Starter Kit adalah basis proyek yang menyatukan framework, styling, database, state management, dan testing dalam satu konfigurasi yang sudah teruji — sehingga Anda bisa langsung menulis fitur tanpa setup dari nol.

## Stack utama

| Lapisan      | Teknologi                                     |
| ------------ | --------------------------------------------- |
| Framework    | Next.js 16 (App Router), React 19, TypeScript |
| Styling      | Tailwind CSS v4, shadcn/ui, tw-animate-css    |
| Database     | Drizzle ORM, postgres-js, PostgreSQL          |
| State server | TanStack React Query (+ DevTools)             |
| Klien API    | Axios                                         |
| Form         | React Hook Form, Zod, @hookform/resolvers     |
| Logging      | Winston                                       |
| Testing      | Vitest, React Testing Library, MSW            |
